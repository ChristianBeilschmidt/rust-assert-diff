# Rust assert_eq! Visual Diff Tool

A tool for visually comparing the `left` and `right` sides of Rust `assert_eq!` panic outputs.

## Usage

1. Run your Rust tests that include `assert_eq!` statements.
2. Copy the panic output containing the `left` and `right` values.
3. Paste the output into the tool's textarea.
4. The tool will display a side-by-side visual diff of the `left` (actual) and `right` (expected) values.
